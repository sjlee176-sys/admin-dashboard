# Admin Dashboard

This repository contains a responsive admin dashboard prototype with:

- Login page
- Sidebar navigation
- Dashboard overview
- Statistics cards
- Data table management
- Chart panel
- Mobile responsive layout

## Files

- `index.html` — page structure
- `styles.css` — dashboard styling
- `script.js` — interaction logic and chart setup

## Run locally

Open `index.html` in a browser.

For a local server, you can also run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
